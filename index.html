학생 조건을 반영해
더 빠르게 배치하세요.

성적, 관계, 시력 조건을 설정하면 개인 자리·짝·모둠 배치에 활용할 수 있는 결과를 만듭니다.

1학생 입력
2조건 설정
3결과 확인

학생 데이터를 어떻게 입력할까요?

계정별로 학생·관계·설정을 DB에 저장합니다. 저장된 데이터는 ‘불러오기’를 눌렀을 때만 화면에 적용되며, 로그인만으로 현재 입력을 덮어쓰지 않습니다.

학생 데이터 입력 방식

학번과 성적을 직접 입력합니다. 예시 데이터는 시연용입니다.

01

학생 데이터

학번, 1~10 정수 성적, 시력 고려 대상 여부를 입력합니다.

입력칸 1개

학생 수를 늘리면 빈 입력칸을 추가합니다. 줄이면 마지막 학생부터 제외합니다.

시력 수치나 실명은 받지 않습니다. 시력 고려 여부만 선택합니다.

02

학생 간 관계

두 학생이 친구인지 앙숙인지 입력합니다. 친구의 배치 방식은 오른쪽 조건에서 따로 선택합니다.

입력된 관계가 없습니다. 필요한 관계만 추가합니다.

앙숙 분리는 친구 관계 설정과 무관한 필수 조건입니다. 같은 두 학생의 관계는 한 번만 입력합니다.

03

배치 조건

이번 배치에서 중요하게 반영할 조건을 고릅니다.

개인 자리: 학생 수 / 짝: 학생 수 ÷ 2 / 모둠: 원하는 모둠 수를 입력합니다.

짝 배치는 학생 수가 짝수일 때 선택할 수 있습니다.

개인 자리에서는 한 줄의 학생 수입니다. 모둠 배치에서는 한 줄의 모둠 수입니다.

성적 분포
친구끼리 배치 방식

필수 조건 · 앙숙은 서로 다른 그룹

이번 방문에서 생성한 최근 배치와 비교합니다. 로그인하면 저장된 최근 배치도 비교 대상으로 불러옵니다.

저장 버튼을 누르면 학생·관계·설정과 현재 생성된 배치 결과를 함께 저장합니다. 배치 계산만으로는 DB를 덮어쓰지 않습니다.

반영도 계산 기준

성적 균등은 그룹 평균 차이가 작을수록, 불균등은 같은 그룹의 성적이 비슷할수록 높습니다. 친구·앙숙은 입력된 관계 중 조건을 충족한 비율입니다. 시력은 고려 대상 중 맨 앞줄에 앉은 비율이며, 중복 회피는 같은 그룹의 학생 쌍 중 이전에 함께 배치되지 않은 비율입니다.

배치도가 화면보다 넓으면 배치도 안에서 좌우로 스크롤할 수 있습니다. 선택한 가로 열 수는 유지됩니다.

입력 변경 확인

SUPABASE AUTH

계정으로 로그인

이메일 계정별로 학생 데이터를 저장합니다. 다른 계정에는 내 학생 데이터가 표시되지 않습니다.

비밀번호는 이 사이트의 학생 DB에 저장하지 않으며 Supabase Auth에서 관리합니다.
